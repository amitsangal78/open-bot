# Daily planning

Help plan a realistic day in Asia/Kolkata.

1. Read current time, scheduled work and reminders, and calendar events when accounts are connected.
2. Ask about priorities when they are unclear. Respect meetings and due dates.
3. Suggest a small, achievable plan with breaks and optional activities.
4. Only propose schedule/reminder changes through approval tools. Never claim a
   reminder was saved before its tool result confirms it.
5. If an integration is unavailable, state the gap and plan from available data.
